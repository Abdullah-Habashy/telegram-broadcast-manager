# Telegram Broadcast Manager

لوحة تحكم لإدارة جهات اتصال بوت تليجرام وإرسال رسائل جماعية (Broadcast) — جدولة، قوالب، تصنيفات، وتقارير نجاح/فشل.

## الستاك

- **Backend:** Node.js + Express 5 + Telegraf (بوت تليجرام)
- **قاعدة البيانات:** PostgreSQL
- **الجدولة:** node-cron (يفحص كل دقيقة)
- **الواجهة:** EJS + JS عادي (من غير خطوة build منفصلة)

## التشغيل محليًا (للتجربة)

```bash
npm install
cp .env.example .env
# افتح .env واملأ DATABASE_URL و SESSION_SECRET و ENCRYPTION_KEY

# ولّد قيمة عشوائية لـ SESSION_SECRET و ENCRYPTION_KEY بالأمر ده (شغّله مرتين، واحدة لكل واحد):
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

npm run migrate   # ينشئ كل الجداول في قاعدة البيانات
npm run dev        # يشغّل السيرفر مع إعادة تشغيل تلقائي عند أي تعديل
```

هيفتح على `http://localhost:3000`. سجّل حساب جديد من `/register`، وبعدين روح **الإعدادات** وسجّل توكن البوت.

> ملحوظة: لو `PUBLIC_URL` مش متحدد، البوت هيتسجل بس مش هيستقبل تحديثات (زي `/start` أو الرسائل)، لأن الـ Webhook محتاج دومين عام بـ HTTPS. للتجربة المحلية ده متوقع، وهيشتغل عادي أول ما تنشره.

## النشر (Deployment) — عشان يفضل شغال من غير توقف

البوت لازم يفضل عملية شغالة طول الوقت (مش Serverless زي Vercel)، عشان يستقبل الرسائل ويبعت الرسائل المجدولة. الأنسب لبداية المشروع:

1. **Render** (الأبسط والأثبت لسيناريو "سيرفر شغال طول الوقت + قاعدة بيانات"):
   - أنشئ **Web Service** جديد من مستودع الكود، واختر باقة مدفوعة صغيرة (الفري تير بيقفل بعد 15 دقيقة خمول، مش هيفيد بوت لازم يفضل سامع)
   - أنشئ **PostgreSQL** من نفس اللوحة، وحط الـ Internal Database URL في `DATABASE_URL`
   - في Environment، ضيف باقي المتغيرات من `.env.example` (`SESSION_SECRET`, `ENCRYPTION_KEY`, `PUBLIC_URL` = رابط السيرفس اللي Render بيديهولك)
   - شغّل `npm run migrate` مرة واحدة (من الـ Shell بتاع Render) قبل أول تشغيل

2. بديل: **Railway** (تسعير حسب الاستهلاك، تجربة استخدام أسهل، بس الفاتورة متغيرة)

## هيكل المشروع

```
src/
  server.js              نقطة البداية
  config/                إعدادات البيئة والاتصال بقاعدة البيانات
  bot/                    منطق بوت تليجرام (botManager + handlers)
  db/                     schema.sql + سكريبت الـ migration
  routes/, controllers/   واجهات الـ API لكل ميزة
  middleware/             حماية الصفحات المحمية بتسجيل الدخول
  jobs/scheduler.js       فحص الرسائل المجدولة كل دقيقة
  utils/crypto.js         تشفير/فك تشفير توكن البوت
  views/                  صفحات EJS (تسجيل دخول، تسجيل، لوحة التحكم)
public/style.css          التنسيق
```

## نقط محتاجة قرار لاحقًا

- التسجيل حاليًا مفتوح لأي حد يعمل حساب — لو عايزين نقفله بدعوة بس، ده تعديل بسيط في `auth.controller.js`
- `response_rate` في الإحصائيات تقريب بسيط (رسائل واردة ÷ رسائل مُرسلة)، مش معدل رد دقيق لكل عملية إرسال — ممكن نظبطه لو عايزين تعريف أدق
