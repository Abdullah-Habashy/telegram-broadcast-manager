# التصحيح المحلي — من غير رصيد API

تصحيح الأسئلة المقالية (نص أو صورة بخط الإيد) على جهازك باستخدام **Claude Code** اللي إنت
مشترك فيه أصلًا، بدل ما يتخصم من رصيد Anthropic API.

**الفكرة:** بتنزّل الإجابات وصورها من الإنتاج، بتصحّحها محليًا على دفعات، بتراجع الأرقام،
وبعدين بترفعها. التلات خطوات منفصلة عن بعض عن قصد — تقدر توقف بينهم وتراجع، والرفع مالوش
أي أثر غير لما تقول `--apply`.

---

## قبل ما تبدأ

١. **Claude Code CLI مثبّت وداخل بحسابك:**
```bash
claude --version      # لازم يطلع رقم
```

٢. **بيانات السيرفر في `.env`** (الملف ده متجاهَل في git، فمفيش خطر على المستودع العام):
```
GRADER_SSH_HOST=root@<ip السيرفر>
GRADER_SSH_KEY=C:/Users/<إنت>/.ssh/<اسم المفتاح>
```
الاتنين دول موجودين في `ACCOUNTS.md`. الباقي ليه قيم افتراضية:
`GRADER_REMOTE_APP=/root/app` · `GRADER_REMOTE_DB=telegram_broadcast_manager`

**مساحة الشغل بره المستودع** (`~/.quiz-local-grader`) لسببين: جوّاها صور إجابات طلبة
حقيقيين ومالهاش مكان في ريبو عام، و`claude` بيحمّل `CLAUDE.md` من مجلد التشغيل وطالع —
فالشغل جوه المشروع كان هيضيّع توكنز في تعليمات مالهاش لازمة. غيّرها بـ`GRADER_WORK_DIR`.

---

## الاستخدام

```bash
# ١) نزّل اللي مستني تصحيح
node tools/local-grader/pull.js --quiz 14

# ٢) صحّح (يقدر يقف ويكمّل من مكانه في أي وقت)
node tools/local-grader/grade.js --quiz 14

# ٣) شوف هيتغيّر إيه — من غير ما يتغيّر حاجة
node tools/local-grader/push.js --quiz 14

# ٤) نفّذ
node tools/local-grader/push.js --quiz 14 --apply
```

### خيارات تنفع

| الأمر | الخيار | معناه |
|---|---|---|
| `pull` | `--limit 50` | جزء بس، للتجربة |
| `pull` | `--images-only` | الإجابات المصوّرة بس |
| `pull` | `--all` | المقالي كله حتى المتصحّح — لإعادة تصحيح اختبار قديم |
| `grade` | `--batch 12` | حجم الدفعة (الافتراضي ٨) |
| `grade` | `--limit 16` | عدد إجابات محدود، للتجربة |
| `grade` | `--model opus` | نموذج تاني (الافتراضي `sonnet`) |
| `grade` | `--show-prompt` | يطبع البرومبت ومايناديش النموذج |
| `push` | `--apply` | التنفيذ الفعلي (من غيره تجربة) |

**درجات الموظفين مستثناة في كل المسارات** (`graded_by <> 'staff'`) — الأداة بتصلّح شغل
النموذج، مابتلغيش حكم بني آدم. نفس قاعدة `queueQuizRegrade`.

## الأرقام اللي اتقاست

على إجابات حقيقية من اختبار الباب الأول، بسعر القايمة:

| الطريقة | لكل سؤال | الزمن |
|---|---|---|
| الـAPI المدفوع | $0.014 | ~3 ث |
| Claude Code — سؤال لوحده | $0.265 | 65 ث |
| Claude Code — ٣ في نداء | $0.100 | 24 ث |

كل نداء لـ`claude -p` بيحمّل تعليمات Claude Code وأدواته قبل أي شغل: حمل ثابت ~$0.25
للنداء، وزيادة حقيقية ~$0.018 للسؤال. **علشان كده الدفعات**: ٨ أسئلة في نداء توصل
~$0.05 للسؤال، و٢٠ توصل ~$0.03.

**الأرقام دي مش فلوس بتدفعها** — على الاشتراك بتتحسب من حد الاستخدام. لو الحد خلص،
السكربت بيستنى ربع ساعة ويكمّل من نفس المكان لحد ٨ مرات، واللي اتصحح محفوظ.

## المعيار واحد في المسارين

قواعد التصحيح كلها في **`src/utils/quizGradingRules.js`**، ومسار الـAPI
(`src/utils/quizGrading.js`) والأداة دي الاتنين بيقروا منه.

**متكتبش قاعدة تصحيح جوه `tools/`.** أي قاعدة تتكتب في مكان واحد بس معناها إن الطالب
اللي اتصحح محليًا اتحاسب بمعيار غير زميله، ومحدش هيلاحظ غير لما يتقدّم تظلم.

## ملفات الشغل

جوه `~/.quiz-local-grader/quiz-<رقم>/`:

| الملف | فيه إيه |
|---|---|
| `manifest.json` | الإجابات وأسئلتها ومراجعها زي ما اتسحبوا |
| `images/` | صور الإجابات |
| `results.jsonl` | كل حكم أول ما يرجع — **ده اللي بيخلي الشغل يكمّل من مكانه** |
| `failed.jsonl` | اللي النموذج ماردّش عليه. شغّل `grade.js` تاني وهياخدهم |

`results.jsonl` بيتكتب إضافة مش استبدال، و`push.js` بياخد **آخر** سطر لكل سؤال — يعني
إعادة تصحيح سؤال بعينه بتغلب القديم.

## لما حاجة تقع

| الشكل | السبب |
|---|---|
| `ناقص GRADER_SSH_HOST` | حط السطرين في `.env` |
| `claude رجع 1` | مش داخل بحسابك — شغّل `claude` عادي مرة |
| دفعات بتفشل ورا بعض | صغّر `--batch`، النموذج بيتوه في الدفعة الكبيرة |
| `X صورتها مانزلتش` | الملف اتمسح من السيرفر — الإجابة بتتصحّح من نصها لو فيه نص |
